# 🔥 PhnkEditz YT Booster (YouTube Shorts SEO & Metadata Generator)

An AI & Algorithm-tuned SEO Metadata Generator built specifically for **Phonk, Music, Car Drift, Gym Motivation, and Anime AMV creators** to break through the 1k-views algorithm barrier.

---

## ⚡ Key Features

1. **Viral Title Suite (5–8 Hook Variations)**:
   - High-CTR curiosity loops (`POV: The Bass Drops at 3 AM... 💀`)
   - Bracket & sound descriptors (`[SLOWED + REVERB]`, `[4K 60FPS]`, `[MONTAGEM]`)
   - YouTube Shorts character counter (< 80-100 characters)
2. **YouTube Studio Tag Cloud (500 Character Limiter)**:
   - Mix of broad, mid-tail, and hyper-niche phonk tags.
   - Calculates exact character count against YouTube Studio's 500-char limit.
   - 1-click comma-separated copy ready for paste.
3. **High-Retention SEO Description**:
   - Naturally integrated keywords, track credits placeholders, and subscribe CTAs.
   - Built-in copyright fair use disclaimer.
   - In-place editable before copying.
4. **Trending Hashtag Hub**:
   - Curated high-velocity tags (`#phonk`, `#phonkmusic`, `#driftphonk`, `#shorts`, `#caredit`).
5. **Competitor & Viral Trend Bank**:
   - Structural formulas deconstructed from 1M+ view phonk videos.
   - High-volume producer/artist reference index.
6. **Creator Pro Guides**:
   - Best upload time schedule (IST & EST peak hours).
   - High-CTR Thumbnail text hook recommendations.
7. **Local History & Favorites**:
   - Automatically saves past generations locally in browser storage with instant search and favorites.
8. **Hybrid AI Engine**:
   - 100% functional out-of-the-box with zero configuration using built-in algorithmic heuristics.
   - Optional custom Gemini API key support in Settings for bespoke LLM generations.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
